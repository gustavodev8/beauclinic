# Beau Bloom

Crie uma **landing page MOBILE-FIRST para a Beau Clinic**, clínica de estética e micropigmentação de Alagoinhas-BA.

Essa página será usada principalmente como **LINK NA BIO DO INSTAGRAM**.

Portanto, pense nela primeiro como uma experiência para celular e somente depois adapte para desktop.

## CONTEXTO

Marca:

A BEAU / BEAU CLINIC

A Beau atua desde 2014 e trabalha principalmente com micropigmentação e procedimentos de beleza.

Conceito da marca:

**“Transformar sem mudar a essência.”**

A landing page deve substituir a experiência visual genérica de uma página tradicional de agendamento por uma experiência muito mais bonita, premium e alinhada ao Instagram da empresa.

IMPORTANTE:

A landing page NÃO precisa recriar o sistema de agendamento.

O agendamento continuará sendo feito externamente pelo Trinks.

Portanto, todos os CTAs de:

* Agendar
* Ver horários
* Escolher procedimento
* Quero fazer
* Marcar atendimento

podem direcionar para:

https://www.trinks.com/a-beau-clinic-

# MICROINTERAÇÕES MOBILE

Use Framer Motion.

Animações:

* fade;
* reveal;
* translateY;
* image mask reveal;
* parallax sutil;
* texto aparecendo por linha;
* escala mínima das fotografias.

Não utilizar animações pesadas.

Duração aproximada:

400ms – 700ms.

Usar IntersectionObserver / viewport animations.

---

# TOUCH EXPERIENCE

Todos elementos devem ser pensados para toque.

Botões:

mínimo 48px de altura.

Links:

área de toque confortável.

Carrosséis:

swipe natural.

Não depender de hover para nenhuma funcionalidade importante.

No desktop pode haver hover como melhoria adicional.

---

# PERFORMANCE MOBILE

Isso é MUITO importante porque a pessoa estará vindo do Instagram e pode estar usando 4G/5G.

Priorizar performance.

Utilizar:

React
Tailwind CSS
Framer Motion

Imagens:

AVIF quando possível.

Fallback:

WebP.

Hero:

preload / priority.

Outras imagens:

lazy loading.

Utilizar:

srcset
sizes
responsive images

Não carregar dezenas de imagens imediatamente.

Não usar vídeos pesados automaticamente.

Caso seja usado vídeo:

* extremamente comprimido;
* muted;
* playsInline;
* poster image;
* carregamento somente quando necessário.

Meta:

LCP abaixo de 2.5 segundos em mobile.
